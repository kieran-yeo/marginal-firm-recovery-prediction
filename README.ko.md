# 어떤 한계기업이 회생하는가: 경제충격을 고려한 외감기업 회생 예측

**유비온 금융 빅데이터 분석 부트캠프 팀 프로젝트 (2022년 6~7월) · 팀 기사회생(企死回生), 4명 · 팀장** · [English](README.md)

경제충격으로 부실해진 기업 중 어떤 기업이 이듬해 회생하는지, 그리고 그 신호가 평상시와 다른지를 연구했습니다. 외감기업을 대상으로 한계기업을 두 가지로 정의하고, 경제충격기간 3개와 정상기간 3개를 비교하며 회생 여부를 예측했습니다.

> **데이터 안내.** 원래 분석은 재배포할 수 없는 유료 재무 데이터베이스 TS2000을 사용했고, 원본 코드는 남아 있지 않습니다. 이 저장소는 최종 발표자료와 팀 기록을 바탕으로 **재구성**한 것입니다. 노트북은 같은 재무 항목을 가진 **합성 패널 데이터**로 전체 파이프라인을 실행하므로, 노트북의 모든 수치는 시뮬레이션 결과입니다. 아래 원래 결과는 최종 발표자료에서 가져왔습니다.

## 연구 설계

| | |
|---|---|
| 대상 | 외감기업 (금융사, 특수목적회사 제외) |
| 한계기업 | ① 2년 연속 이자보상배율 1 미만 (한국은행 기준) 또는 ② 2년 연속 영업손실 (신보·기보 기준) |
| 회생 (타깃) | 3년차에 이자보상배율 1 이상 또는 영업이익 실현 |
| 충격기간 | 닷컴버블 붕괴 2000–01, 글로벌 금융위기 2007–08, 유럽 재정위기 2011–12 (경기순환 저점 기준 2년) |
| 정상기간 | 2014–15, 2015–16, 2016–17 |
| 데이터셋 | 정의 2개 × 기간 6개 = 12개 |
| 후보 변수 | 28개: 재무비율 20개(성장성·수익성·활동성·안정성), 한국은행 기업취약성 비율 5개(레버리지·유동성), 더미 3개(매출 규모, 업종, 자산 규모) |
| 변수 선택 | 데이터셋별 로짓 모형: 상관계수 0.8 이상이면 더 유의한 변수를 남기고, p < 0.05 기준 후진제거법 |
| 모델 | 로지스틱 회귀, 의사결정나무, kNN, ANN, 랜덤포레스트, XGBoost, DNN; 그리드 서치 튜닝; 8:2 분할; F1, ROC-AUC |
| 강건성 검증 | 한 기간으로 학습하고 같은 유형의 다른 기간으로 평가 |

## 원래 결과 (TS2000 데이터)

각 기간 유형 3개 데이터셋의 F1 / ROC-AUC 평균입니다.

| 모델 | 이자보상배율: 충격 | 이자보상배율: 정상 | 영업손실: 충격 | 영업손실: 정상 |
|---|---|---|---|---|
| 로지스틱 | **0.855 / 0.901** | **0.888 / 0.919** | 0.761 / 0.827 | 0.848 / 0.889 |
| 의사결정나무 | 0.677 / 0.766 | 0.734 / 0.804 | 0.803 / **0.851** | 0.792 / 0.866 |
| kNN | 0.478 / 0.620 | 0.602 / 0.705 | 0.785 / 0.820 | 0.778 / 0.825 |
| ANN | 0.470 / 0.662 | 0.757 / 0.818 | 0.750 / 0.787 | 0.855 / 0.891 |
| 랜덤포레스트 | 0.757 / 0.843 | 0.814 / 0.861 | 0.803 / 0.834 | 0.841 / 0.875 |
| XGBoost | 0.764 / 0.830 | 0.831 / 0.875 | **0.813** / 0.846 | 0.846 / 0.881 |
| DNN | 0.665 / 0.756 | 0.782 / 0.869 | 0.793 / 0.831 | **0.885 / 0.945** |

최종 데이터셋은 177~1,032개 기업이었고, 회생 비율은 25~45%였습니다.

**주요 결과**

- 수익성 지표는 모든 데이터셋에서 유의했고, 매출·자산·차입금 관련 지표는 대부분의 데이터셋에서 유의했습니다.
- 기간 유형보다 한계기업 정의(이자보상배율 vs 영업손실)에 따라 선택된 변수가 더 크게 달랐습니다.
- 앙상블 모델(랜덤포레스트, XGBoost)은 모든 데이터셋에서 고르게 좋았고 교차 기간 검증에서도 가장 안정적이었습니다. 신경망 모델은 편차가 가장 컸습니다.
- 정책 제언: 공통으로 유의한 지표의 집중 관리, 한계기업 선정 기준의 다양화, 앙상블과 딥러닝의 복합 활용.

## 재구성에서 더한 것

[`notebooks/marginal_firm_recovery.ipynb`](notebooks/marginal_firm_recovery.ipynb)는 원천 재무 항목으로 비율 계산, 한계·회생기업 라벨링, 로짓 기반 변수 선택, 모델 6개 튜닝, 교차 기간 검증까지 전체 과정을 다시 만들어, 유료 데이터만 있으면 재실행할 수 있게 했습니다.

또한 이런 예측에서 중요한 설계 원칙을 문서로 남겼습니다. **피처는 결과 이전 연도에서만 가져와야 한다**는 것입니다. 원래 분석에서도 피처는 한계기업이었던 2년의 재무비율만 썼고, 3년차는 회생 여부를 판정하는 데만 썼습니다. 재구성도 같은 원칙을 따릅니다. 이 원칙이 왜 중요한지 보여주기 위해, 노트북에서는 회생 연도의 비율로 데이터셋을 다시 만들어 비교했습니다. 합성 데이터에서 로지스틱 회귀의 ROC-AUC가 약 0.77에서 0.99로 뛰는데, 그 비율이 이미 결과를 담고 있기 때문입니다.

## 한계

- 연말 결산 데이터라 연중에 시작된 충격을 반영하지 못합니다.
- 2년 기간 설정이 모든 위기에 맞지는 않으며, 충격에서 부실·회생까지의 시차를 고려하지 못했습니다.
- 정의에 쓰인 변수(이자보상배율, 영업이익)는 제외했지만, 밀접하게 관련된 비율들이 피처에 남았습니다.
- 합성 패널은 데이터 구조를 재현할 뿐 실제 관계를 재현하지 않으므로, 그 결과를 원래 수치와 비교하면 안 됩니다.
